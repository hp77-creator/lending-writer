## Before you start coding

The exercise is open-ended on purpose. We don't tell you what to build — we hand you a situation and a dataset.

Before writing any code, we recommend:

1. Read `BRIEF.md` end to end. Don't skim it. The "Your Job, In Three Parts" section in particular tells you exactly what we'll be looking for.
2. Open `data/applications.json` and skim a few applications.
3. Open a few PDFs from `data/documents/` — at least one salaried profile, one self-employed, one that looks "easy", one that looks "hard".
4. **Pretend to be each of the candidate users for 5 minutes.** Be a loan officer. Then a risk analyst. Then an ops head. Notice what each of them would actually want from this dataset and an LLM. That's how you'll figure out who to build for.
5. Write the **product memo** (Part 1 in the brief) before opening your editor.
6. *Then* start building.
